## Learning chess

The `learning-chess` branch turns this repo into a chess-learning workspace for Claude Code:
play with live coaching, review your real games with Stockfish, and follow structured lessons.
See [CHESS-SETUP.md](CHESS-SETUP.md) to set it up and get started.

## Hold On

An LLM-native chess coach built on this branch by a team of agent partners: a real game in which a
move that gives material away does not land until you answer one question on the board. Source
in `app/`, spec in `product/PRODUCT.md`, live page linked from `app/README.md`.
